## Soil Erosion Decision Support System (DSS) — ICAR-NBSS&LUP

Developed at ICAR-NBSS&LUP, Nagpur, this GIS and R-based Decision Support System calculates soil erosion risks using the Revised Universal Soil Loss Equation (RUSLE) for the Vidarbha region.
Technologies used: R Language, R Shiny, Terra, RUSLE, GIS, Google Earth Engine (GEE), Leaflet, Data Science.
Key features:
- Geospatial data ingestion (IMD rainfall, DEM, Landsat imagery, NDVI, soil datasets) and automated RUSLE factor calculation.
- Interactive map overlays showing high soil-loss risk zones across districts.
- Automated reporting and conservation recommendations for agricultural planners and policymakers.
- Integration with an R Shiny dashboard and chatbot assistant for interactive scenario analysis.

## Aarogyam Health Locker

Aarogyam is a modern digital health locker platform designed to help patients and doctors manage medical records smoothly and securely, inspired by the Government of India's Ayushman Bharat Digital Mission (ABDM).

Technologies used: React, TypeScript, Web Application, UI/UX, Healthcare AI.

- Doctor dashboard for real-time prescription and medical history access.

- Responsive design with dark and light mode UI.

## Pneumonia Detection using Machine Learning

An AI-based medical imaging classification model that analyzes chest X-ray radiographs using deep convolutional neural networks (CNNs) to assist with early and accurate pneumonia diagnosis.
Technologies used: Python, Machine Learning, Deep Learning, PyTorch, CNN, Medical AI.
Key features:
- Deep learning classification pipeline trained on chest X-ray datasets.
- Grad-CAM visual heatmaps highlighting affected lung regions.
- Web interface for instant radiograph upload and real-time inference.
- High accuracy and sensitivity metrics on validation benchmarks.

## Safety Kit Detection (PPE Detection)

A real-time computer vision solution using YOLOv11 and OpenCV to detect whether industrial workers are wearing required Personal Protective Equipment (PPE) such as helmets, safety vests, and goggles.
Vedant also published a research paper related to his Safety Kit Detection project.
Technologies used: Python, YOLOv11, OpenCV, Computer Vision, Real-Time Detection.
Key features:
- Real-time multi-person safety gear tracking via live video feeds.
- Automated bounding boxes for helmets, high-visibility vests, and safety goggles.
- Instant alert logging and compliance monitoring dashboard.
- Optimized model inference for edge devices and IP cameras.

## Aapla Shetkari (आपला शेतकरी — Smart Farmer Assistant)

A comprehensive smart farming and AI-powered agricultural decision support platform built for Indian farmers.
Technologies used: Large Language Models (LLMs), Voice AI, React, Smart Farming, Agriculture AI.
Key features:
- Natural language chat and voice query input in regional languages (Marathi, Hindi, English).
- AI-driven crop disease diagnosis via user-uploaded plant photos.
- Real-time market price updates, expense tracking, government schemes, and local weather advisories.
- Intuitive, high-contrast mobile interface tailored for rural farmers.
